# しりとり画伯 サポートページ

App Store Connect の「サポートURL」用の静的ページです。

## 公開手順（GitHub Pages）

1. この `support` フォルダの内容（少なくとも `index.html`）を、公開用の GitHub リポジトリに置く
2. GitHub リポジトリの **Settings → Pages**
3. **Source** を `Deploy from a branch` にする
4. Branch を `main`、フォルダを `/ (root)`（または `docs`）にして Save
5. 数分後、表示される URL を開いてページを確認する

例（root に `index.html` を置いた場合）:

`https://<GitHubユーザー名>.github.io/<リポジトリ名>/`

## App Store Connect への入力例

サポートURL:

`https://<GitHubユーザー名>.github.io/<リポジトリ名>/`
